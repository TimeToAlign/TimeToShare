# 0002. Use JSON Schema 2020-12

Date: 2026-10-09

## Context

TimeToShare manifests cross Python, JavaScript, and tools that do not share a
single implementation language. They need a public, versioned interchange
contract.

## Considered options

- JSON Schema 2020-12.
- TypeBox-authored schema.
- A model-emitted format.
- Protobuf or Avro.
- Write a format and validator ourselves.

## Decision

Publish JSON Schema 2020-12 as the normative format. The TimeToAlign
maintainers can review plain JSON, and the bus factor is not tied to a
TypeScript build tool. Primary sources are https://json-schema.org/draft/2020-12/json-schema-core
and https://github.com/json-schema-org/json-schema-spec/blob/main/LICENSE.

## Consequences

The schema is compact, has no runtime transitive dependencies, and carries an
OSI-compatible specification licence. Validator packages select their own
implementations. A schema-only release fits a low release cadence; exiting to
another IDL costs generated bindings and migration tooling, whereas writing it
ourselves would create that burden now.
