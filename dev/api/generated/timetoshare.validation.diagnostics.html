timetoshare.validation.diagnostics#

The validator’s diagnostics and the small readers every rule module shares.

The error a rule raises with its code and path, the JSON pointer of a path, the readers of a schema-checked object’s members, and the walks of the IDs of a root’s tree and of the whole manifest, which read any value. A leaf module: it imports no rule module and no validator, so the rule modules and timetoshare.validate both import it without a cycle.

timetoshare.validation.diagnostics.connected_sets(pairs)[source]#

Map every member of the pairs to the representative of its connected set.

Two members share a representative exactly when a chain of pairs joins them (union-find with path halving). The MatchStamp rule counts the sets a named MatchStamp’s anchors form; the table types group the unique anchors of a MatchClaim table into potential MatchStamps by it.

timetoshare.validation.diagnostics.tree_ids(root, path)[source]#

Yield every ID of a root’s tree with its path, in the order of the rules.

The timelines depth first, each with its conversion maps’, regions’ and flow-control elements’ IDs before its children’s; then the IDs of the maps other maps hold, timeline by timeline in the same order, each held map before those it holds, a CombinationMap’s outputs by name in code-point order. An element that is no object or holds no string id is passed over, so the walk reads any value.

timetoshare.validation.diagnostics.listed_ids(manifest)[source]#

Yield the IDs of the elements a manifest lists outside its timelines.

The groups, the MeasureMaps, the named timestamps, the elisions, the named MatchStamps, each followed by its alignment anchors, the resources, the FlowMaps and the virtual timelines, in that order, each with its path. An entry that is no object or holds no string id is passed over, so the walk reads any value.

timetoshare.validation.diagnostics.manifest_ids(manifest)[source]#

Yield every ID of a manifest with its path, in the order of the rules.

Each root’s tree (tree_ids), then the listed elements (listed_ids), then the manifest’s own id. The walk reads any value.

timetoshare.validation.diagnostics.timelines_by_id(manifest)[source]#

Return every timeline of a manifest, at any depth, by ID.

timetoshare.validation.diagnostics.axes_by_id(manifest)[source]#

Return every timeline of a manifest, at any depth, and every virtual timeline, by ID: what a named timestamp, a group member or a resource may name.

Of a repeated ID the first in this order is kept, the timelines in document order before the virtual timelines.
