timetoshare.tables.columns#

The columns of the two table types and the cells they hold.

A number is three members, filled by its number type and never mirrored: an int is its numerator alone, a fraction its numerator and its denominator (at least 1), a float its finite value alone; every other member is null. A coordinate cell of the MatchClaim table adds the unit and the number_type of its coordinate; a row of the Projections table states them once, in its own unit and number_type columns, for its start and its duration. number_cell() writes a number’s members and coordinate_value() reads them back.

Both tables’ columns and the structs of their cells are read from one file, tables.json beside the manifest schema (tables_path()), never declared a second time here.

An AlignmentAnchor: one coordinate of each of the row’s two timelines, coordinate_a on its timeline_a_id, coordinate_b on its timeline_b_id.

The members of a row’s provenance: the keys of the provenance schema.

How it was made, then who believes it, in the schema’s order. The manifest’s entries add property and value, which a row needs no more than it needs a subject: the row is what the entry is about.

timetoshare.tables.columns.coordinate_value(cell, number_type=None)[source]#

The exact value of a well-formed number, read from its number type.

A fraction is read in whatever terms it is written: (2, 4, null) is the value 1/2.

Parameters:

  • cell (Mapping[str, Any]) – A coordinate cell, or a Projection’s start or duration.

  • number_type (str | None) – The number type the row states, for a Projection’s number; None reads the cell’s own number_type.

timetoshare.tables.columns.fixture_path(name)[source]#

The path of one file of the table fixture, by its name.

The fixture is a manifest (manifest.yaml), its two tables (match_claims.parquet, projections.parquet) and the anchors and potential MatchStamps expected of the MatchClaim table (expected.yaml).

timetoshare.tables.columns.number_cell(value, number_type)[source]#

The members of a number of the number type number_type.

An int takes an integer (or a Fraction whose denominator is 1), a fraction an integer or a Fraction, written as its numerator and denominator, a float a finite float or an integer a double holds exactly; a float is never written as a Fraction, nor a Fraction as a float, and an exact number’s members are 64-bit integers.

Raises:

ValueError – If number_type is no number type or value is no number of it.

timetoshare.tables.columns.tables_path()[source]#

Return the path of the column types of the two tables, tables.json.

The one source of MATCH_CLAIM_SCHEMA and PROJECTION_SCHEMA: its types declare the structs a cell holds, its tables each table’s status and its columns, in order.
