DEFAULTS#

const DEFAULTS: object;

Defined in: defaults.ts:41

The default of every key that has one, by the kind of object holding it. A timeline’s number_type defaults to its unit’s default number type, which the unit table UNITS states. Every conversion map has the keys of conversion_map; a LinearMap adds those of linear_map and a TableMap those of table_map. Every flow-control element has the keys of flow_control_element and every destination of a jump those of jump_destination; a destination’s repeat_count has no default, its absence meaning no limit. Every FlowMap has the keys of flow_map and every virtual timeline those of virtual_timeline; the manifest’s flow_maps and virtual_timelines have no default and are never added. Every named timestamp of graphical.timestamps has the keys of timestamp, a match timestamp (matchstamp: true) those of match_timestamp instead, and every alignment anchor of a named MatchStamp those of alignment_anchor, and every elision of graphical.elisions those of elision (its width has none). A resource has no defaults. @context, statements and provenance have no default and are never added or removed. Python’s timetoshare.defaults holds the same table, and the schema declares each value as the key’s default.

Read a text as JSON, whatever its first character, after removing one U+FEFF at position 0, without losing a number or the order of a key.

Integers keep their exact value (a bigint beyond the safe range), floats stay floats (an integral float is a JsonFloat), and an object’s keys keep their written order even where JavaScript would list array-index keys first. The text -0 is the integer 0.

withReferencesRenamed()#

function withReferencesRenamed<T>(manifest, renamed): T;

Defined in: statements/statements.ts:721

The manifest with the references to renamed elements renamed or dropped. The keys and values of renamed are bare IDs. A reference is the text "#" + old exactly (other.yaml#old names an element of another manifest and is none) where statements name things: a node’s id, a provenance entry’s basis and stated_by items, its service and a belief’s actor, in the statements and provenance of the manifest, of every timeline at any depth and of every region, and of every node within them, a node in an entry’s value included. Where renamed[old] is an ID, each reference becomes "#" + renamed[old]. Where it is null, a value that is a node naming the element leaves its list, an entry whose value names it leaves provenance, a basis or stated_by item naming it leaves its list, a belief whose actor it is leaves beliefs and a service naming it is deleted; then every list of values, container, basis, stated_by, beliefs and provenance left empty is deleted, as are a node without id and ordered values left without anything. Each reference is renamed once: with {a: "b", b: "c"}, #a becomes #b and #b becomes #c. The elements’ own IDs are never read, so either ID form is taken. Python’s with_references_renamed gives the same values.
