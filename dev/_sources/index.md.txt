# TimeToShare!

TimeToShare! is an exchange format for the structures of musical timelines.
This site holds its documentation: the format, its two specifications, the
JSON Schema, and the API of the Python package `timetoshare` and the npm
package `@timetoalign/timetoshare`, which validate, read and write it.
